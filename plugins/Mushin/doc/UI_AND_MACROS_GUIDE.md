# Mushin UI, Controls, Pages & Macro Reflection Guide

This document explains how every control type, panel, page, visualizer, and macro interaction in **Mushin** was built for Akai MPC standalone hardware, as a reference for future updates and plugins.

---

## 1. Pages & Function-Key Tab Architecture

The MPC touch screen has **6 hardware function keys** (`F1`–`F6`) along the bottom. Mushin defines **8 logical pages** in [`ui.json`](../ui.json) and maps them onto the 6 function keys in [`bin/make_skin.py`](../bin/make_skin.py):

| Logical Page | `fnKeyIndex` | `fnKeySubIndex` | Purpose |
|---|---:|---:|---|
| `MAIN` | 0 | 0 | 8 Performance Macro Orbs (2 Q-Link banks) |
| `S-CURVE` | 1 | 0 | S-Curve Waveshaper (`Active`, `Gain`) + Info Decay (pixelated `#FF4D8D` row viz) |
| `FILTER` | 2 | 0 | Filter A (Cyan) & Filter B (Magenta), `CLN`/`VOWL`/`ACID`/`DIGI`, `Filt Mix`, `Routing`, dual `XYPad`s |
| `LFO` | 3 | 0 | LFO 1 & 2 (`LFO 1 X × LFO 2 Y` `XYPad`) + Noise Oscillator |
| `LFO MTX` | 3 | 1 | LFO 1 & 2 Modulation Matrix (sub-tab of `LFO`) |
| `GATE` | 4 | 0 | Trance Gate (128 patterns, 16 tappable `Step` buttons, `Offset`, `AHDS` `Envelope`) |
| `PUMP` | 4 | 1 | Sidechain Pumper (`Ratio`, `Mix`, `IN`/`DUCK` vertical meters, independent target toggles) |
| `DLY+LIM` | 5 | 0 | Stereo Delay + Final Limiter (`LIMITER GR` horizontal meter) |

### Q-Link Alignment & Compaction
- `ui.json` sets `"qlinkGroups": "rows"` so every 4-column row of controls corresponds to one hardware Q-Link bank (`Q-Link 13..16`, `9..12`, `5..8`, `1..4`).
- Leaving an entire visual row `"empty"` causes `tools/gen_ui.py` to emit an all-`-1` Q-Link bank, creating a dead bank when cycling Q-Links.
- `bin/make_skin.py` compacts `Screen Mode Q-Links` on `MAIN` (Tab 1) and `LFO` (Tab 4) into consecutive top-down banks (`13..16` → `9..12` → `5..8`) and remaps `Tab`/`SubTab` indices to match `fn_key_map` (`LFO MTX` → `Tab 4 SubTab 2`, `PUMP` → `Tab 5 SubTab 2`, `GATE` → `Tab 5 SubTab 1`, `DLY+LIM` → `Tab 6 SubTab 1`).

## 2. Panels, Dual-Engine Theming & Q-Badge Margins

Each page uses a `1280×628` background PNG generated by [`bin/make_panels.py`](../bin/make_panels.py):
- **Active pill contrast**: Unselected dark background `#0D0F12` matches MPC's active-tab contrast styling cleanly.
- **Engine A / B theming**: Engine A / LFO 1 / Input sections use **Cyan (`#00E5FF`)** while Engine B / LFO 2 / Ducking sections use **Magenta (`#FF4D8D`)** (`knobUniMag`, `knobBiMag`, `radioFTypeMag`, `radioFModeMag`, `radioLfoWaveMag`, `puck_magenta.png`, `meter_duck`).
- **Q-Badge clearance (`indent_top_left_labels`)**: Hardware Q-Link overlays place a yellow `Q` badge in the top-left corner of control cards; `indent_top_left_labels()` shifts native `Name` / value `Label` bounds slightly right (`+18 px`) so text never collides with the yellow `Q` badge.
- **Static `Text` label rule**: `"type": "Text"` labels need `"handleName": "Invalid"` and `"showWhenDataModelInvalid": "Show"` so the MPC never hides them.

## 3. Controls & Custom Visualizers

### 3.1 Knobs, Faders & Toggles
- **Unipolar / Bipolar Knobs**: `knob_uni.png` (`knob`) and `knob_bi.png` (`polarity: "bipolar"` for `LFO MTX`, `SC Amount`, and `Gate Offset`).
- **Horizontal Faders**: `fader_h_uni.png` (`248×36`) for `Gain`, `Mix`, `Level`, `SC Mix`, and `Gate Start/Hold/End`.
- **Boolean Switches**: `toggle_{on,off}.png` (`S-Curve Active`, `Exhaustion`, `Auto Gain`, `Decay Active`, `Exh Link`, `Noise Active`, `Gate Active`, `SC Active`, `SC Drive/Cut/Gain/Reso`, `Delay Active`, `Delay Sync`, `Limit Active`).

### 3.2 Baked Icon Segmented Switches (`2–6` choices)
- [`bin/make_button_icons.ps1`](../bin/make_button_icons.ps1) composites anti-aliased icons onto `seg2` (`122×40`), `seg3` (`80×40`), `seg4` (`58×40`), and sliced `46×40` / `38×40` canvases (`New-SegCanvas`):
  - `A Type` / `B Type` (`radioFType` / `radioFTypeMag`, 4): Clean (sine), Vowel (`VOWL` dual formant peaks), Acid (303 spike), Digital (staircase).
  - `A Mode` / `B Mode` (`radioFMode` / `radioFModeMag`, 4): LP, HP, BP, Notch.
  - `Routing` (`radioRoute`, 2), `Noise Route` (`radioNRoute`, 3), `Gate Rate` (`radioGRate`, 3), `Delay Tempo` (`radioDTempo`, 4), `Limit Mode` (`radioLMode`, 2), `SC Mode` (`radioScMode`, 2), `LFO 1/2 Wave` (`5`), `Noise Type` (`6`).

### 3.3 Telemetry `XYPad`s & `Meter`s (Non-Automatable Mirror Parameters)
MPC telemetry widgets bind to read-only non-automatable parameters updated at ~30 Hz in `process()` (only after `blocksSinceReset_ > 4` so `host_sim` Check 3 chunk round-trip stays clean):
- **Filter A & B `XYPad`s (`FILTER`)**: Bind `A Cut X/Y` & `A Res`, `B Cut X/Y` & `B Res` to show live LFO/macro/sidechain modulated cutoff and resonance via `puck_cyan.png` & `puck_magenta.png`.
- **LFO `XYPad` (`LFO`)**: `make_lfo_xypad` binds non-automatable `kLfo1Pos` (`lfo1_pos`) & `kLfo2Pos` (`lfo2_pos`) using `puck_lfo.png`.
- **Pump Vertical Meters (`PUMP`)**: `make_pump_meter` binds `kScInMeter` (`SC In`, direction `Up`, cyan) and `kScDuckMeter` (`SC Duck`, direction `Down`, magenta).
- **Limiter Horizontal Meter (`DLY+LIM`)**: `make_pump_meter` binds `kLimGrMeter` (`Lim GR`, direction `Right`, cyan-to-magenta gradient `meter_lim_{off,on}.png`).

### 3.4 Dynamic `Image` `FilmStrip`: Info Decay Row (`S-CURVE`)
- [`bin/make_panels.py`](../bin/make_panels.py) generates `decay_viz_strip.png` (`629×1600`, 25 frames stacked vertically): Frame 0 is 100% transparent; Frames 1–24 add an increasing zone-matched `#FF4D8D` wash and pixelated squares growing from `2 px` to `16 px` (`8%` to `62%` density).
- Inserted at index `0` of `S-CURVE`'s `componentsData` behind Row 3 controls (`type: "Image"`, `imageType: "FilmStrip"`, `numFrames: 25`, `acceptsHWFocus: "No"`), driven by non-automatable `kDecayViz` (`Decay Viz`).

### 3.5 128-Pattern Trance Gate, Tappable Steps, Offset & Envelope (`GATE`)
- `kGateMasks[128]` provides 128 unique rhythmic patterns across 8 musical banks via `Gate Pattern` (`"overlay": "menu"` knob).
- Rather than a giant 128-frame strip (which would exceed MPC embedded GPU texture limits), Row 2 Cols 1–3 hold **16 interactive `Button` toggles** (`gate_step_0..15` using `47×56` `step_{on,off}.png` / `step_beat_{on,off}.png`), bound to automatable `Step 1..16` parameters. Selecting a pattern populates the steps; tapping any step customizes the active rhythm live.
- `Gate Offset` (`-100%..+100%` of a step) shifts the gate envelope phase relative to the beat so kick transients can pass cleanly.
- `Envelope` (`AHDS`, Row 4) links `Gate Start`, `Gate Hold`, `Gate End`, and `Gate Floor` (bidirectionally synced with `Gate Depth`).

## 4. Performance Macros & Preset Synchronization (`Mushin.cpp`)

1. **`baseValues_[kNumParams]`**: Stores pre-macro values (saved in `"MSHB"` chunk data via `saveExtraState` / `loadExtraState`).
2. **Bidirectional updates**: Moving macros calls `applyMacros()` and `notifyHostParameterChanged()`; editing detail controls inverse-maps into `baseValues_` via `updateBaseFromTarget()`.
3. **Preset Changes (`effSetProgram`)**: Whenever `currentProgram() != lastProgram_` in `process()`, `Mushin` calls `requestDisplayUpdate()` (`audioMasterUpdateDisplay`) and `notifyHostParameterChanged(i)` for all automatable parameters (plus resets meter cache flags in `reset()`) so every knob, icon switch, step toggle, and macro orb snaps immediately to the loaded preset across all **96 built-in programs** (`115` total parameters `0..114`).

## 5. Build & Skin Regeneration Workflow

```powershell
# 1. Regenerate backgrounds, gate step PNGs, & Info Decay filmstrip
python plugins/Mushin/bin/make_panels.py

# 2. Regenerate button icons (PowerShell)
powershell -ExecutionPolicy Bypass -File plugins/Mushin/bin/make_button_icons.ps1

# 3. Regenerate TUI.json & Q-Links.json (invoke build.py first if params.json changed)
python plugins/Mushin/bin/make_skin.py

# 4. Compile native + arm32 + arm64 and validate assets/TUI.json
python tools/build.py plugins/Mushin

# 5. Run host_sim verification (20 checks, 115 params, 96 programs)
.sdk-tools/host_sim plugins/Mushin/build/native/mushin.dll test
```
